# Licenciamento e histórico dos direitos — FAEG

Este documento esclarece as condições de licenciamento do projeto acadêmico e operacional **FAEG — Sistema Web de Gestão Logística**.

## Situação atual

A partir do commit que incluir o novo arquivo [`LICENSE`](../LICENSE), as **novas contribuições originais**, na extensão dos direitos de seus respectivos titulares, passam a ser disponibilizadas **sem concessão geral de uma licença aberta** (*todos os direitos reservados*). Isso **não** significa que todo o código atual deixou de ser MIT.

O `LICENSE` não concede permissão geral para reutilizar, modificar ou comercializar essas novas contribuições sem autorização dos titulares. Para apresentações ou avaliações acadêmicas, a autorização de acesso/uso deve ser combinada com os responsáveis; a visibilidade pública do repositório, por si só, não equivale a uma licença proprietária para terceiros.

## Histórico da MIT

1. O arquivo `LICENSE` do repositório anteriormente publicado identificava **MIT License — Copyright (c) 2026 Felipe Pontes**.
2. As versões e os materiais efetivamente disponibilizados sob MIT **continuam** licenciados nessa condição. A alteração posterior do arquivo na branch `main` não revoga direitos já concedidos a quem recebeu essas versões.
3. A versão exata de cada entrega deve ser identificada pelo **histórico de commits**; não presumir que toda a história foi reescrita pela licença atual.
4. O texto integral da MIT antes utilizada foi preservado em [`licenses/MIT-VERSOES-ANTERIORES.txt`](../licenses/MIT-VERSOES-ANTERIORES.txt), incluindo a atribuição exigida.
5. A incorporação de código previamente MIT em versões posteriores continua sujeita à MIT para esse código. A nova política pode proteger as **contribuições inéditas** que seus titulares tenham direito de licenciar de forma restritiva.

## Titularidade e contribuições

- **Felipe Pontes** constava como detentor dos direitos autorais na licença MIT original.
- O projeto tem participação de outras pessoas na implementação e na definição das regras operacionais. O aviso anterior não é prova suficiente para resolver todos os direitos patrimoniais de todas as contribuições.
- **FAEG Ltda** é a organização de aplicação do projeto; o uso da marca e a titularidade do código são questões diferentes. Recomenda-se formalizar autorização de uso entre os desenvolvedores e a empresa antes de exploração comercial ou cessão de direitos.
- Dependências de terceiros mantêm suas próprias condições de licenciamento; não alterá-las nem remover seus avisos.

## Orientação ao mantenedor

- Confirmar a concordância dos titulares de direitos antes de mudar as condições de **contribuições futuras**.
- Se o projeto for estratégico e conter dados sensíveis, preferir repositório privado; mudar `LICENSE` **não** oculta o histórico Git de um repositório público.
- Para divulgação acadêmica, disponibilizar as evidências, documentação e acesso com o escopo autorizado, sem publicar credenciais ou dados operacionais reais.
- Se houver versões anteriormente distribuídas com MIT, manter as obrigações de atribuição e os direitos relativos a essas versões.

Este texto é uma orientação documental e não substitui análise jurídica de titularidade e licenciamento para uso empresarial.
